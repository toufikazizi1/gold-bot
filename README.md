# بوت الذهب XAU

تطبيق أندرويد يتداول الذهب (XAUUSDT) على باينانس Futures، بوقف خسارة متحرك.

## التنزيل
1. افتح تبويب **Releases** في الريبو وحمّل `gold-bot.apk`.
2. ثبّته (فعّل "التثبيت من مصادر غير معروفة").

## الاستعمال
- يبدأ في مود **Paper** (فلوس وهمية، أسعار حقيقية). جرّبو أولا.
- الإعدادات في أسفل التطبيق: المود، مفاتيح باينانس، الرافعة، أقصى صفقة، حد الخسارة اليومي.
- مفتاح باينانس: **Futures + Trade** فقط، بلا Withdraw، مقيّد بـ IP.
- للمود الحقيقي اكتب `LIVE` في خانة التأكيد ثم احفظ.

## الوقف المتحرك
- SL: خسارة قصوى بالدولار. TP: ربح هدف.
- وقف متحرك: عند ربح بمقدار هذه القيمة، الوقف ينتقل لنقطة الدخول ثم يتبع أعلى ربح بنفس المسافة.
- في المود الحقيقي الوقف يتحط ويتحرك **داخل باينانس** (أمر STOP_MARKET عبر Algo Order API)، فالصفقة تبقى محمية حتى إذا سكرت التطبيق.
- إذا فشل وضع الوقف عند الدخول، التطبيق يسكّر الصفقة فورا.

## حدود
- الدخول بالإشارات يتم فقط والتطبيق مفتوح والشاشة مشعولة.
- XAUUSDT قد يتطلب توقيع اتفاقية TradFi في حسابك على باينانس وتوفر حسب البلد.
- ما فيه ضمان ربح.

## تطوير
`node test.js` يختبر المنطق. التطبيق ملف واحد: `www/index.html`. الـ APK يتبنى تلقائيا عبر GitHub Actions عند كل push على `main`.
